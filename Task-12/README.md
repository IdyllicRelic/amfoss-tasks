# Task-12: TimeFlow Wallpaper Sync
A simple application that updates your wallpaper with text from a text file and displays the time

## Usage
**NOTE: You must be using the Gnome desktop environment and in light mode for this to work!**
### Dependencies
- Gnome
- python
- pip

### Installation
```bash
python3 -m venv .venv
source .venv/bin/activate

pip install -r requirements.txt
python3 main.py # or run 'make'
```
